######### DOCKER #########

docker compose up -d                -> (-d) runs it in the background
docker compose ps                   -> should show the container as running
docker compose config               -> shows config (ALSO SHOWS PASSWORD)
docker compose down                 -> stop and remove the containerdocker compose down
